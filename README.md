# Mi tarjeta de presentación en React

## Descripción
Este proyecto consiste en la creación de tarjetas de presentación
utilizando React y Vite.

Se desarrollaro una tarjetas utilizando un mismo
componente funcional llamado Tarjeta.

## Instalación

Ingresar a la carpeta:

cd mi-tarjeta-react

Instalar dependencias:

npm install

Ejecutar el proyecto:

npm run dev
